# 组件边界

网站和机器人共用一份违规业务存储。网站账户、会话、邀请码、群域授权和草稿保存在独立平台库；账户的 QQ 资料字段不授予机器人权限。

Web 通过内部 Unix socket 调用 NapCatBot 中的结构化业务桥，复用原业务引擎。业务记录、成员计数、来源归因和幂等结果在业务事务内提交；网站不维护第二份违规主库。桥实现随 NapCatBot 版本发布，Web 仓库保留客户端和跨仓测试。

管理员活跃度分析使用 QQ 作为人员标识，分别统计业务群聊天、管理群聊天和系统业务操作。算法组件提供小时与每日快照、周/月窗口和人工反馈调优；数据覆盖不足时保留缺失状态。权限投影由 Web 账号与群域控制。现有违规周月榜和管理员活跃度是不同功能，具体接口与计数规则见私有 Web/Algorithm 文档。

主仓库仅含文档、版本锁、子模块和公开结构检查。生产配置、数据、证据、QQ 登录态、账号映射、密钥、虚拟环境和导出文件不属于源码仓库。

私有仓库 CI 在 GitHub 托管机器上运行，不在生产服务器运行任意 PR 代码。现有机器人和 Hermes 的服务权限保持原状态；独立的受限部署账户不代表机器人已改为非 root 运行。
